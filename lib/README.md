## 一、本库现在有什么（已落盘）

### 1. 毛泽东著作（完整原文）

- 来源：GitHub `Jack-year/-`（毛泽东选集全集 markdown，含 1991 年第二版出版说明）
- 内容：

### 2. 马克思、恩格斯著作（完整原文，中英双版本）

- **全集中文（最全，50 卷）**：`马克思恩格斯著作/马恩全集中文/` → `第1卷.md` … `第50卷.md`（50 MB）

  - 含全部著作、文章、书信与手稿（卷 27–39 主要为书信卷）。查冷门篇目请从这里找。
- **中文译本（13 部精选，日常速读用这份）**：`马克思恩格斯著作/清洗文本中文/`
  - 来源：`marx-zh-cn.github.io`（《马克思恩格斯全集》第一版中文，MEW-ZH 各卷）

  - 马克思 8 部：共产党宣言、资本论 第一/二/三卷、关于费尔巴哈的提纲、德意志意识形态、哥达纲领批判、法兰西内战

## 三、怎么用
- **人工阅读**：直接打开对应 `.md` / HTML 文件，按卷、按篇检索（文件内可 Ctrl+F）。
- **AI 调用**：本目录含 `SKILL.md`，可让 WorkBuddy 把「窑洞一号」当作资料型 skill 加载，用于：找某篇原著原文、引用毛主席/马恩语录、总结某篇著作要点、对照不同版本等。
- **离线优先**：全部为本地文件，无需联网即可使用。
